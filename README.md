# WORDLE 

## Technologies used
1. HTML
2. CSS
3. Javascript

## Description
Wordle is a  word puzzle where players get six tries to guess a hidden five-letter word. After each guess, the tile colors change to show which letters are correct and in the right spot, correct but in the wrong spot, or not in the word at all.
## User Stories
1. As a User, I want to type a five-letter word.
2. As a User, I want the game to check if my guessed word is correct.
3. As a User, I want letter tiles to change color(green, yellow,gray)
4. As a User, I want an on-screen keybored that updates letter color and shows how many tries i have left.
5. As a User, I want to see a won or lost message.
